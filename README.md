# ACTIVIDAD 2
- Git: Es un sistema de control gratuito que realiza cambios en un código o un proyecto en equipos. 

- Github: Es una plataforma que almacena archivos en la nube mediante el código git para trabajar en equipos. 

- Repositorio: Un lugar donde se puede guardar y proteger la información física o digital. 

- Commit: Es un cambio que se queda guardado en una captura permanente. 

- Colaborador: Es una persona con acceso a hacer cambios directos en un repositorio específico. 

- Readme: Es como un manual de instrucciones de un proyecto. 


 1.Github sirve principalmente para almacenar proyectos en equipo
